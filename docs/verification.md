# 验证记录 · 2026-11-13

本记录区分真实硬件、程序测试与尚未验证的范围。所有电量只是采样时刻的读数，不是保证未来相同。

## 真实硬件

- **Alto Keys K98M**：通过本机 **046D:C548 Bolt** 接收器，槽位 1；HID++ 根节点回复协议 **4.5**；读到电量 **95%**、Keyboard、Receiver、Online、未充电。已确认该固件长报表请求有效；短报表 ping 存在无回复的情况。
- **ATK A9 Ultra Max 2.0 Tri-Mode**：**373B:11FE** 接收器，Windows 控制通道 **FF02 / usage 2，17 字节输入输出**；Compx 返回电量 **75%**、Mouse、Receiver、Online、未充电。通过 CID 1 / MID 15 解析实际鼠标名称。
- Windows 同时保留 K98M 的蓝牙离线缓存 **100%**；它不是实时电量，维持 Offline 并置灰。组件第一页优先展示当前在线的键盘和鼠标。
- 已读到实际 CPU 负载与物理内存占用；没有把初次 CPU 差分缺失填成 0。
- 本机未安装 **PawnIO**；CPU 温度正确显示不可用并给出驱动需求。没有自动安装驱动，也没有宣称已验证真实温度读数。
- 天气服务真实网络测试：地理搜索返回城市，天气请求返回当前温度与 5 个后续小时数据。测试城市未写入用户配置。

## 程序检查

- Release 编译，无编译警告/错误。
- 控制台断言覆盖 HID++ 帧相关性、两类错误、截断/超界/粗略电量、ATK 校验码/异步事件/实际录制帧、同名不同槽位、基于物理容器合并、持续负载、休眠间断、冷却、离线与充电过滤、失败退避、天气本地时间、PushPlus 响应语义、配置校验、损坏配置和 DPAPI。
- PushPlus 用本地 HTTP 假处理器验证；**没有发送真实外部推送**。用户绑定后的端到端微信送达尚未测试。
- 72 项程序断言通过。x64 self-contained 启动/采样/退出与 Python 兼容入口进行了运行检查。x86 self-contained 在本机 WOW64 下执行原生 HID 扫描，识别到相同的 30 个接口与 K98M 95% 在线读数；这不代替 32 位 Windows 10 的独立硬件验证。
- x64、x86、ARM64 self-contained 版本均已编译发布；ARM64 未在 ARM 电脑上运行验证。外观预览由 WPF 实际绘制器生成，并明确标记示例数据。

## 0.2.3 主题、分页与便携目录

347 项核心检查及 290 项 WPF 检查通过。新增三种主题保存、控件/提示框主题传播、设备顺序在连接状态变化时保持稳定，以及滚轮分页边界、惯性事件和细粒度累积检查。新配色由实际绘制器生成示例预览。分页使用 120 单位累积和 180ms 间隔，达到首末页停止；不再循环翻页。

便携目录分为根启动器、app 程序目录、说明与许可、使用说明。根启动器为 AnyCPU 的 .NET Framework 4.x 小程序，调用 Windows 自带框架；主程序按架构自带 .NET 10。根启动器转发参数、等待命令行模式返回，普通启动后退出；根启动器与整个 app 目录必须一起保留。ARM64 依旧只有编译发布，未在 ARM 实机运行。

## 0.2.2 字体与连续缩放

组件字号 85–125%，字重 300/400/500/600/700；数字按可用宽度适配、长设备名省略，待办文本与输入同步。字体配置有校验与持久化。设置中新增平滑缩放开关，默认开启。

移除组件大小滑块的 5% 吸附；拖动更新按 Render 优先级合并、落盘延后 350ms，关闭设置时补存。单独缩放不重建交互层、不主动重绘全部内容；原生透明窗口预留最大显示区域，内容通过 RenderTransform 和单次缓存做 150ms 缓出，结束后移除缓存和动画时钟并收回窗口边界。中断后从当前动画值接续。原有显示模块布局变更直接重排。

340 项核心检查、286 项 WPF 检查通过。新增字体边界和保存重载、连续小数缩放、中间动画帧、快速反向调整后的最终尺寸、缓存及时钟清理、字号与字重控件检查。已检查默认设置页及最大字号/半粗体的实际渲染。已运行新版启动/采样/设置页/退出检查。未进行各显卡和刷新率的逐帧性能基准测试。

## 0.2.1 悬停提示

统一天气、外设、指标、工具栏与待办的 ToolTip 样式，圆角 12、紧凑宽度、自动换行、半透明主题色与轻阴影。首次停留 800ms，移开关闭。提示框主题显式绑定其所属控件，支持提示已打开时切换主题；同一区域控件更换提示内容时复用 Popup，避免闪烁。重建待办交互层前关闭旧提示。外设提示去掉协议与诊断细节。

280 项 WPF 检查通过，新增实际 Popup 打开、宽度与长文本换行、跨 Popup 的深色继承及实时切换、更新内容时保持打开、延迟与移开关闭检查。效果预览由实际打开的 WPF 提示框渲染，使用示例信息。

## 0.1.1 圆角修复

移除 `SetWindowCompositionAttribute` 的独立矩形 Acrylic 背景以及整数像素窗口区域；材质和悬停工具栏统一使用 WPF 的逐像素透明圆角裁剪，裁剪随 Viewbox 缩放。现为半透明渐变材质，不提供实时背景模糊。之前的设计预览只绘制 WPF 内容，未包含原生背景层，不能验证系统合成后的边角。

独立窗口检查程序验证 2 种主题、5 种组件缩放和 4 种渲染 DPI 密度，360 项像素断言通过：四角及其内侧采样均完全透明、中心材质非透明。尚未覆盖所有显示驱动、远程桌面与多屏切换环境。

便携启动验证：x64 根启动器转发 --smoke 至带空格和中文的路径，主程序退出码 0，生成真实采样与六页设置截图；x86 根启动器在本机转发 --render-themes，退出码 0。根目录四项结构已检查。尚未在单独的 32 位 Windows 和 ARM 实机验证根启动器。

x86、ARM64 安装器编译成功；尚未在独立 32 位 Windows 与 ARM 实机执行安装。安装程序未做商业代码签名。应用二进制与之前通过验证的 0.2.3 便携版相同，本次增加安装脚本与发布文档。
