# 应用内更新

0.7.11 起，在设置 → 关于使用“检查更新”。自动检查和接收预览版均可独立关闭，默认开启。自动检查在启动后稍作等待，并按 24 小时间隔复查；发现版本只提示，不自动下载安装。网络失败后稍后重试，也可以随时手动检查。

选择“下载并重启更新”后，程序下载当前进程架构对应的附件。x86 程序在 64 位 Windows 上仍更新为 x86。安装版使用 setup；便携版使用 ZIP，保留原来解压位置。下载可取消，完成大小与 SHA256 校验并确认更新助手准备好之后才退出旧版。

程序使用 GitHub 上 cqc0101/Mizu 的公开 Release，无需登录或填写 Token。关闭预览版更新时，只接受正式发布版本。下载地址和跳转域名受到限制，ZIP 也检查架构、必需文件、路径越界、链接、重复文件与解压大小。

更新助手临时运行，不安装常驻服务。它先备份程序和 %LOCALAPPDATA%\Mizu 的数据，再替换文件或调用现有安装程序；等待新版完成启动确认。下载失败时旧版继续运行；安装失败、新版启动崩溃或确认超时会恢复程序及更新前的数据，重新启动旧版。

若更新助手被中断，重新运行根目录 Mizu.exe 会检查恢复标记并继续处理；也可保留备份后重新安装程序。请勿在更新过程中删除 app、恢复标记或 %LOCALAPPDATA%\Mizu-Updates。恢复失败时会保留资料并显示备份位置，不会将其自动清除。

%LOCALAPPDATA%\Mizu-Updates 保存下载、更新日志和本机备份，其中可能包含私人设置、单词本以及加密凭据，请勿上传此目录。后续准备更新时清理更早的成功记录，保留最近一次成功备份；失败和中断的资料保留供恢复使用。

首次升级到 0.7.11 仍需手动安装或完整解压，因为旧版本没有更新入口。使用自定义受保护目录、目录联接、符号链接或系统策略限制时，程序可能拒绝原位更新；可改用独立可写文件夹或手动安装。当前过程不自动更新或重装 PawnIO 驱动。
