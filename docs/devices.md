## 通用路径

蓝牙优先使用 Windows 提供的电量属性；标准 HID 仅在设备暴露 BatteryStrength Feature 时可读。系统缓存可能延迟刷新。离线旧读数会明确置灰，最多保留 24 小时。

罗技实现 HID++ 2.0 电量特性 0x1004 / 0x1000、设备名称类型与接收器槽位。HID++ 1.0 和电压推算未实现。Bolt、Unifying、Lightspeed 中采用相应协议的设备仍需逐型号验证。

ATK / VXE 使用白名单和 Compx / BitMouse 协议。目录中的型号用于识别，不能据此宣称全部兼容。未知设备不会被随机报文探测。

## 提交设备反馈

使用仓库的“设备适配”问题模板，填写完整型号、连接方式、Windows 版本、组件版本、厂商软件读数，以及组件中的表现。可从设置导出诊断，提交前查看内容；不要上传 settings.json、Token、序列号或完整 HID 路径。

同一设备的蓝牙与 2.4G 模式请分别记录。对于未知协议，先提供厂商公开资料或经过整理的协议证据，再讨论实现与实机验证。
