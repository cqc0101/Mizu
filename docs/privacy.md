# 数据与权限

0.3.3 诗词源升级到 v2.jinrishici.com。该服务会按来源 IP 推测地区并记录推荐历史；客户端首次启用时获取匿名 Token，后续请求复用。Token 以当前用户 DPAPI 加密存于本地 poetry-token.dat，不进入日志或发布包，不与其他用户共用。关闭模块不发起后续诗词请求。

- 本地目录：`%LOCALAPPDATA%\Mizu`，包含设置、待办、日志和电量缓存。源码仓库与发布包不包含该目录。
- 推送 Token：通过 Windows DPAPI / CurrentUser 加密保存。加密配置仍属于私人文件，不应上传。
- 天气：设置城市后请求 `geocoding-api.open-meteo.com` 与 `api.open-meteo.com`，无自动定位。
- 推送：用户填写 Token 并启用后，请求 `www.pushplus.plus`；只在组件运行时监控。
- 温度：用户主动安装官方 PawnIO 后，按需以管理员身份读取传感器；不自动安装驱动或修改系统安全策略。
- 开机启动：用户选择后写入当前用户注册表 Run 项。
- 无遥测或广告。诊断包含型号、VID/PID、当前读数及哈希标识，不包含 Token、原始 HID 路径与序列号；公开提交前仍请查看内容。
- 网络模块默认关闭。开启后读取选定活动网卡的字节计数，并按约 2 秒节拍向最多 8 个配置 IP（初始 1.1.1.1）分别发送 ICMP 探测；全部超时会延长实际采样间隔；目标可看到来源 IP。关闭网络模块后停止探测。丢包与延迟仅为此目标的探测结果。
- 媒体模块默认关闭。开启后只在本地读取 Windows 当前媒体会话的标题、作者与播放状态；操作按钮向对应会话发送播放控制，不上传曲目信息。

依赖、服务条款与驱动来源见 [第三方声明](../THIRD-PARTY-NOTICES.md)。

天气缓存仅包含城市坐标与天气数据，保存在 %LOCALAPPDATA%\Mizu\weather-cache.json，可从设置清除；不会随发布包分发。

每日诗词默认关闭。开启后按设置访问 v2.jinrishici.com，无需个人账号、不上传城市或媒体信息；服务端可见请求来源 IP，并可能据此推荐诗词。缓存诗词、作者、朝代、出处与取得时间，数据保存在 poetry-cache.json；匿名客户端凭据加密存储在 poetry-token.dat。

0.4.0 天气主源失败时可向 wttr.in 发送所选城市坐标；天气页可关闭此备用。内置 30 条公版诗句不需要网络，不属于批量采集的接口缓存。最近离线选择存于 poetry-cache.json.local，与 poetry-cache.json 中的在线缓存分开；匿名诗词 Token 仍仅在用户本机加密保存。

0.5.0 隐藏 IP 只影响组件与悬停提示，设置列表仍显示地址供管理。蓝牙监听只读取本机已配对设备的 Windows 连接属性，不扫描附近未配对广播，不主动配对或改变连接。原始蓝牙地址仅在内存中匹配，不进入电量缓存、诊断或日志；型号、连接类型与哈希标识仍可能出现在诊断中。
